# Capstone 1 

Sales Performance analysis project using SQL and the sample_sales database.

## Sales Territory
Sales Manager: Jim Heck
State: Colorado
Region: West

## Project Overview
  The purpose of this project was to analyze sales and information regarding Jim Heck's Colorado EmporiUm stores using the sample_sales database.
Using SQL, I examined sales revenue, trends over the months and years, average sales, and I also ranked how well his 18 stores were doing compared to each other. I used my findings to identify important business trends and insights.
  I exported my SQL findings into Microsoft Excel to create a clean visual representing my data insights. I organized the insights using worksheets with PivotTables and charts.
    The goal of this project is to provide Jim Heck with a clearer understanding of the sales and performance of his stores by identifying trends and highlighting key information for improving EmporiUm throughout Colorado.
